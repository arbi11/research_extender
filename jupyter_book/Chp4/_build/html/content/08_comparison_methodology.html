8. Comparison Methodology#

8.1 Introduction to Comparative Analysis#

Rigorous comparison between reinforcement learning (Q-Learning) and evolutionary algorithms (Genetic Algorithm) requires a systematic experimental design that ensures fair, reproducible, and meaningful results. This chapter establishes the methodological framework for evaluating the relative performance of these optimization approaches in the context of electrical machine topology optimization.

8.1.1 Importance of Methodological Rigor#

Comparative analysis in optimization research serves several critical purposes:

  • Algorithm Selection: Guide practitioners in choosing appropriate methods

  • Performance Understanding: Reveal strengths and weaknesses of each approach

  • Research Validation: Provide credible evidence for scientific claims

  • Benchmark Establishment: Create reference points for future work

  • Insight Generation: Understand algorithmic behavior characteristics

8.1.2 Comparison Challenges#

Comparing stochastic optimization algorithms presents unique challenges:

Stochastic Nature:

  • Random variations lead to different results across runs

  • Need for statistical analysis to draw meaningful conclusions

  • Importance of multiple independent runs

Parameter Sensitivity:

  • Performance depends heavily on hyperparameter settings

  • Fair comparison requires appropriate parameter tuning

  • Different optimal parameter sets for each algorithm

Computational Cost:

  • Different algorithms require varying computational resources

  • Need to consider convergence speed vs. solution quality

  • Trade-offs between exploration and exploitation

8.2 Experimental Design Framework#

8.2.1 Problem Specification#

Domain: Synchronous Reluctance Motor (SynRM) rotor topology optimization

Objective Function: $\(\max_{\mathbf{x} \in \{0,1\}^{n \times n}} T_{\text{avg}}(\mathbf{x})\)$

Constraints:

  • Material usage: \(\sum_{i,j} x_{i,j} \leq 0.7 \times n^2\)

  • Connectivity: All iron regions must be connected

  • Manufacturing: Minimum feature size ≥ 1 cell

Test Cases:

  • Small: 5×5 grid (25 variables)

  • Medium: 7×7 grid (49 variables)

  • Large: 9×9 grid (81 variables)

8.2.2 Algorithm Configurations#

Q-Learning Configuration:

q_learning:
  episodes: 100
  learning_rate: 0.8
  gamma: 0.95
  epsilon_max: 1.0
  epsilon_min: 0.1
  epsilon_decay: 0.05
  max_steps: 15

Genetic Algorithm Configuration:

genetic_algorithm:
  population_size: 100
  generations: 50
  crossover_prob: 0.8
  mutation_prob: 0.1
  tournament_size: 3
  elitism_ratio: 0.1

8.2.3 Experimental Variables#

Independent Variables:

  • Algorithm type (Q-Learning vs GA)

  • Problem size (5×5, 7×7, 9×9)

  • Random seed (for reproducibility)

  • Computational budget (fixed FEA evaluations)

Dependent Variables:

  • Best achieved fitness (torque)

  • Convergence speed (evaluations to reach 90% of best)

  • Solution consistency (variance across runs)

  • Computational efficiency (time per evaluation)

Controlled Variables:

  • Hardware platform (same computational resources)

  • Fitness evaluation (identical electromagnetic solver)

  • Termination criteria (consistent stopping conditions)

  • Implementation language (Python 3.8+)

8.3 Performance Metrics#

8.3.1 Primary Performance Metrics#

Solution Quality:

  • Best Fitness: \(f_{\text{best}} = \max_{k \in \text{runs}} f_k^*\)

  • Mean Fitness: \(\bar{f} = \frac{1}{N} \sum_{k=1}^{N} f_k^*\)

  • Standard Deviation: \(\sigma_f = \sqrt{\frac{1}{N-1} \sum_{k=1}^{N} (f_k^* - \bar{f})^2}\)

Convergence Metrics:

  • Convergence Rate: Evaluations to reach 90% of best fitness

  • Early Performance: Fitness after 25% of budget

  • Improvement Rate: Average fitness gain per 100 evaluations

Efficiency Metrics:

  • Time per Evaluation: Average computational time

  • Memory Usage: Peak memory consumption

  • Scalability: Performance degradation with problem size

8.3.2 Secondary Performance Metrics#

Algorithm Behavior:

  • Diversity Maintenance: Population/solution diversity over time

  • Exploration-Exploitation Balance: Ratio of exploratory vs. exploitative actions

  • Stagnation Detection: Periods without improvement

Solution Characteristics:

  • Topology Complexity: Number of flux barriers, connectivity

  • Manufacturability: Constraint violation count

  • Robustness: Sensitivity to small perturbations

8.3.3 Statistical Analysis Methods#

Descriptive Statistics:

  • Mean, median, mode, standard deviation

  • Confidence intervals (95% CI)

  • Box plots and distribution analysis

Inferential Statistics:

  • t-test: Compare means of two algorithms

  • ANOVA: Compare multiple algorithms/configurations

  • Wilcoxon signed-rank test: Non-parametric comparison

  • Mann-Whitney U test: Distribution-free comparison

Effect Size Measures:

  • Cohen’s d: Standardized difference between means

  • Cliff’s delta: Non-parametric effect size

  • Vargha-Delaney A: Probabilistic superiority measure

8.5 Statistical Analysis Framework#

8.5.1 Hypothesis Testing#

Primary Hypotheses:

H₀: Q-Learning and Genetic Algorithm achieve equal performance $\(H_0: \mu_{QL} = \mu_{GA}\)$

H₁: Q-Learning and Genetic Algorithm achieve different performance $\(H_1: \mu_{QL} \neq \mu_{GA}\)$

Secondary Hypotheses:

  • Q-Learning converges faster than GA

  • GA produces more consistent results

  • Algorithm performance depends on problem size

8.5.2 Significance Testing#

Normality Assessment:

  • Shapiro-Wilk test for normality

  • Q-Q plots for visual assessment

  • Skewness and kurtosis analysis

Test Selection Criteria:

  • Parametric tests: If normality assumptions met

  • Non-parametric tests: If normality assumptions violated

  • Robust tests: For outlier-resistant analysis

Multiple Comparison Correction:

  • Bonferroni correction: Conservative approach

  • Holm-Bonferroni: Sequential correction

  • False Discovery Rate: Less conservative approach

8.5.3 Effect Size Interpretation#

Cohen’s d Guidelines:

  • Small effect: |d| = 0.2

  • Medium effect: |d| = 0.5

  • Large effect: |d| = 0.8

Practical Significance:

  • Engineering relevance: > 5% torque improvement

  • Computational relevance: > 20% time reduction

  • Consistency relevance: < 10% performance variation

class ComparisonExperiment:
    def __init__(self, config):
        self.config = config
        self.results = {}
    
    def run_experiment(self, algorithms, problem_sizes, n_runs):
        for algorithm in algorithms:
            for size in problem_sizes:
                run_results = []
                for run in range(n_runs):
                    result = self.run_single(algorithm, size, run)
                    run_results.append(result)
                self.results[(algorithm, size)] = run_results
    
    def analyze_results(self):
        return {
            'statistical_tests': self.perform_statistical_tests(),
            'effect_sizes': self.calculate_effect_sizes(),
            'visualizations': self.create_visualizations()
        }

# Comparison Methodology Demonstration
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
from scipy import stats
from typing import List, Dict, Tuple
import pandas as pd
from IPython.display import display, Markdown

class ComparisonMethodologyDemo:
    """Demonstration of comparison methodology for Q-Learning vs Genetic Algorithm"""
    
    def __init__(self, seed=42):
        np.random.seed(seed)
        self.results = self.generate_mock_results()
    
    def generate_mock_results(self) -> Dict[str, Dict[str, List[float]]]:
        """Generate mock experimental results for demonstration"""
        # Simulate Q-Learning results
        ql_results = {
            '5x5': np.random.normal(3.2, 0.15, 30),  # Mean 3.2, std 0.15, 30 runs
            '7x7': np.random.normal(3.1, 0.20, 30),  # Mean 3.1, std 0.20
            '9x9': np.random.normal(2.9, 0.25, 30),  # Mean 2.9, std 0.25
        }
        
        # Simulate Genetic Algorithm results
        ga_results = {
            '5x5': np.random.normal(3.15, 0.10, 30),  # Mean 3.15, std 0.10
            '7x7': np.random.normal(3.05, 0.12, 30),  # Mean 3.05, std 0.12
            '9x9': np.random.normal(2.95, 0.15, 30),  # Mean 2.95, std 0.15
        }
        
        return {
            'q_learning': ql_results,
            'genetic_algorithm': ga_results
        }
    
    def perform_statistical_analysis(self) -> Dict[str, Dict[str, float]]:
        """Perform comprehensive statistical analysis"""
        analysis_results = {}
        
        for size in ['5x5', '7x7', '9x9']:
            ql_data = self.results['q_learning'][size]
            ga_data = self.results['genetic_algorithm'][size]
            
            # Descriptive statistics
            analysis_results[size] = {
                'ql_mean': np.mean(ql_data),
                'ql_std': np.std(ql_data),
                'ql_median': np.median(ql_data),
                'ga_mean': np.mean(ga_data),
                'ga_std': np.std(ga_data),
                'ga_median': np.median(ga_data)
            }
            
            # Normality tests
            _, ql_p_normal = stats.shapiro(ql_data)
            _, ga_p_normal = stats.shapiro(ga_data)
            analysis_results[size]['ql_normal_p'] = ql_p_normal
            analysis_results[size]['ga_normal_p'] = ga_p_normal
            
            # T-test (assuming normality)
            t_stat, t_pvalue = stats.ttest_ind(ql_data, ga_data)
            analysis_results[size]['t_statistic'] = t_stat
            analysis_results[size]['t_pvalue'] = t_pvalue
            
            # Wilcoxon test (non-parametric)
            w_stat, w_pvalue = stats.ranksums(ql_data, ga_data)
            analysis_results[size]['wilcoxon_statistic'] = w_stat
            analysis_results[size]['wilcoxon_pvalue'] = w_pvalue
            
            # Effect size (Cohen's d)
            pooled_std = np.sqrt(((len(ql_data) - 1) * np.var(ql_data) + 
                                (len(ga_data) - 1) * np.var(ga_data)) / 
                               (len(ql_data) + len(ga_data) - 2))
            cohens_d = (np.mean(ql_data) - np.mean(ga_data)) / pooled_std
            analysis_results[size]['cohens_d'] = cohens_d
            
            # Cliff's delta (non-parametric effect size)
            cliff_delta = self.cliffs_delta(ql_data, ga_data)
            analysis_results[size]['cliffs_delta'] = cliff_delta
        
        return analysis_results
    
    def cliffs_delta(self, x: List[float], y: List[float]) -> float:
        """Calculate Cliff's delta effect size"""
        nx, ny = len(x), len(y)
        greater = 0
        equal = 0
        
        for xi in x:
            for yi in y:
                if xi > yi:
                    greater += 1
                elif xi == yi:
                    equal += 1
        
        return (greater - (nx * ny - greater - equal)) / (nx * ny)

    def interpret_results(self, analysis: Dict) -> None:
        """Provide interpretation of statistical results"""
        print("\n" + "="*60)
        print("📊 STATISTICAL ANALYSIS RESULTS")
        print("="*60)
        
        print("\n🔍 NORMALITY TESTS (Shapiro-Wilk):")
        for size in ['5x5', '7x7', '9x9']:
            ql_p = analysis[size]['ql_normal_p']
            ga_p = analysis[size]['ga_normal_p']
            ql_normal = ql_p > 0.05
            ga_normal = ga_p > 0.05
            print(f"  {size}: QL={'Normal' if ql_normal else 'Not Normal'} (p={ql_p:.3f}), "
                  f"GA={'Normal' if ga_normal else 'Not Normal'} (p={ga_p:.3f})")
        
        print("\n📈 T-TEST RESULTS:")
        for size in ['5x5', '7x7', '9x9']:
            t_stat = analysis[size]['t_statistic']
            t_p = analysis[size]['t_pvalue']
            significant = t_p < 0.05
            winner = 'Q-Learning' if t_stat > 0 else 'Genetic Algorithm'
            print(f"  {size}: t={t_stat:.3f}, p={t_p:.3f} - ", end="")
            if significant:
                print(f"Significant difference ({winner} better)")
            else:
                print("No significant difference")
        
        print("\n📏 EFFECT SIZE INTERPRETATION:")
        for size in ['5x5', '7x7', '9x9']:
            cohens_d = analysis[size]['cohens_d']
            cliffs_delta = analysis[size]['cliffs_delta']
            
            # Cohen's d interpretation
            if abs(cohens_d) < 0.2:
                d_interpretation = "negligible"
            elif abs(cohens_d) < 0.5:
                d_interpretation = "small"
            elif abs(cohens_d) < 0.8:
                d_interpretation = "medium"
            else:
                d_interpretation = "large"
            
            # Cliff's delta interpretation
            if abs(cliffs_delta) < 0.147:
                cd_interpretation = "negligible"
            elif abs(cliffs_delta) < 0.33:
                cd_interpretation = "small"
            elif abs(cliffs_delta) < 0.474:
                cd_interpretation = "medium"
            else:
                cd_interpretation = "large"
            
            print(f"  {size}: Cohen's d={cohens_d:.3f} ({d_interpretation}), "
                  f"Cliff's δ={cliffs_delta:.3f} ({cd_interpretation})")
        
        print("\n🎯 PRACTICAL RECOMMENDATIONS:")
        # Overall performance assessment
        ql_overall = np.mean([analysis[size]['ql_mean'] for size in ['5x5', '7x7', '9x9']])
        ga_overall = np.mean([analysis[size]['ga_mean'] for size in ['5x5', '7x7', '9x9']])
        
        if ql_overall > ga_overall:
            print("  • Q-Learning shows higher overall performance")
            print(f"  • Average improvement: {(ql_overall - ga_overall)/ga_overall*100:.1f}%")
        else:
            print("  • Genetic Algorithm shows higher overall performance")
            print(f"  • Average improvement: {(ga_overall - ql_overall)/ql_overall*100:.1f}%")
        
        # Consistency assessment
        ql_std = np.mean([analysis[size]['ql_std'] for size in ['5x5', '7x7', '9x9']])
        ga_std = np.mean([analysis[size]['ga_std'] for size in ['5x5', '7x7', '9x9']])
        
        if ga_std < ql_std:
            print("  • Genetic Algorithm provides more consistent results")
            print(f"  • Lower standard deviation: {ga_std:.3f} vs {ql_std:.3f}")
        else:
            print("  • Q-Learning provides more consistent results")
            print(f"  • Lower standard deviation: {ql_std:.3f} vs {ga_std:.3f}")
