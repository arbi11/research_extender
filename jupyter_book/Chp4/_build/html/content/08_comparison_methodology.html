Comparison Methodology## 8.1 Introduction to Comparative AnalysisRigorous comparison between reinforcement learning (Q-Learning) and evolutionary algorithms (Genetic Algorithm) requires a systematic experimental design that ensures fair, reproducible, and meaningful results. This chapter establishes the methodological framework for evaluating the relative performance of these optimization approaches in the context of electrical machine topology optimization.### 8.1.1 Importance of Methodological RigorComparative analysis in optimization research serves several critical purposes:- Algorithm Selection: Guide practitioners in choosing appropriate methods- Performance Understanding: Reveal strengths and weaknesses of each approach- Research Validation: Provide credible evidence for scientific claims- Benchmark Establishment: Create reference points for future work- Insight Generation: Understand algorithmic behavior characteristics### 8.1.2 Comparison ChallengesComparing stochastic optimization algorithms presents unique challenges:Stochastic Nature:- Random variations lead to different results across runs- Need for statistical analysis to draw meaningful conclusions- Importance of multiple independent runsParameter Sensitivity:- Performance depends heavily on hyperparameter settings- Fair comparison requires appropriate parameter tuning- Different optimal parameter sets for each algorithmComputational Cost:- Different algorithms require varying computational resources- Need to consider convergence speed vs. solution quality- Trade-offs between exploration and exploitation## 8.2 Experimental Design Framework### 8.2.1 Problem SpecificationDomain: Synchronous Reluctance Motor (SynRM) rotor topology optimizationObjective Function:$\max_{\mathbf{x} \in \{0,1\}^{n \times n}} T_{\text{avg}}(\mathbf{x})**Constraints**:- Material usage: \sum_{i,j} x_{i,j} \leq 0.7 \times n^2- Connectivity: All iron regions must be connected- Manufacturing: Minimum feature size ≥ 1 cell**Test Cases**:- **Small**: 5×5 grid (25 variables)- **Medium**: 7×7 grid (49 variables) - **Large**: 9×9 grid (81 variables)### 8.2.2 Algorithm Configurations**Q-Learning Configuration**:```yamlq_learning: episodes: 100 learning_rate: 0.8 gamma: 0.95 epsilon_max: 1.0 epsilon_min: 0.1 epsilon_decay: 0.05 max_steps: 15```**Genetic Algorithm Configuration**:```yamlgenetic_algorithm: population_size: 100 generations: 50 crossover_prob: 0.8 mutation_prob: 0.1 tournament_size: 3 elitism_ratio: 0.1```### 8.2.3 Experimental Variables**Independent Variables**:- Algorithm type (Q-Learning vs GA)- Problem size (5×5, 7×7, 9×9)- Random seed (for reproducibility)- Computational budget (fixed FEA evaluations)**Dependent Variables**:- Best achieved fitness (torque)- Convergence speed (evaluations to reach 90% of best)- Solution consistency (variance across runs)- Computational efficiency (time per evaluation)**Controlled Variables**:- Hardware platform (same computational resources)- Fitness evaluation (identical electromagnetic solver)- Termination criteria (consistent stopping conditions)- Implementation language (Python 3.8+)## 8.3 Performance Metrics### 8.3.1 Primary Performance Metrics**Solution Quality**:- **Best Fitness**: f_{\text{best}} = \max_{k \in \text{runs}} f_k^- **Mean Fitness**: \bar{f} = \frac{1}{N} \sum_{k=1}^{N} f_k^- **Standard Deviation**: \sigma_f = \sqrt{\frac{1}{N-1} \sum_{k=1}^{N} (f_k^* - \bar{f})^2}**Convergence Metrics**:- **Convergence Rate**: Evaluations to reach 90% of best fitness- **Early Performance**: Fitness after 25% of budget- **Improvement Rate**: Average fitness gain per 100 evaluations**Efficiency Metrics**:- **Time per Evaluation**: Average computational time- **Memory Usage**: Peak memory consumption- **Scalability**: Performance degradation with problem size### 8.3.2 Secondary Performance Metrics**Algorithm Behavior**:- **Diversity Maintenance**: Population/solution diversity over time- **Exploration-Exploitation Balance**: Ratio of exploratory vs. exploitative actions- **Stagnation Detection**: Periods without improvement**Solution Characteristics**:- **Topology Complexity**: Number of flux barriers, connectivity- **Manufacturability**: Constraint violation count- **Robustness**: Sensitivity to small perturbations### 8.3.3 Statistical Analysis Methods**Descriptive Statistics**:- Mean, median, mode, standard deviation- Confidence intervals (95% CI)- Box plots and distribution analysis**Inferential Statistics**:- **t-test**: Compare means of two algorithms- **ANOVA**: Compare multiple algorithms/configurations- **Wilcoxon signed-rank test**: Non-parametric comparison- **Mann-Whitney U test**: Distribution-free comparison**Effect Size Measures**:- **Cohen's d**: Standardized difference between means- **Cliff's delta**: Non-parametric effect size- **Vargha-Delaney A**: Probabilistic superiority measure## 8.4 Experimental Protocol### 8.4.1 Run Protocol**Standard Run Structure**:1. **Initialization**: Set random seed, load configuration2. **Environment Setup**: Create SynRM optimization environment3. **Algorithm Execution**: Run optimization with resource limits4. **Result Collection**: Store fitness history, final solution5. **Post-processing**: Analyze solution characteristics6. **Cleanup**: Release computational resources**Resource Allocation**:- **Maximum FEA evaluations**: 10,000 per run- **Time limit**: 2 hours per run- **Memory limit**: 8 GB RAM- **CPU cores**: 4 parallel threads### 8.4.2 Repetition Strategy**Number of Runs**:- **Minimum**: 30 independent runs per algorithm- **Preferred**: 50 runs for statistical robustness- **Validation**: Additional 20 runs for final validation**Random Seed Management**:- **Fixed seeds**: For reproducible baseline runs- **Random seeds**: For statistical variation- **Seed logging**: Record all seeds used in experiments**Run Scheduling**:- **Batch processing**: Run multiple configurations in parallel- **Resource sharing**: Distribute computational # Comparison Methodology Demonstrationimport numpy as npimport matplotlib.pyplot as pltimport seaborn as snsfrom scipy import statsfrom typing import List, Dict, Tupleimport pandas as pdfrom IPython.display import display, Markdownclass ComparisonMethodologyDemo:    """Demonstration of comparison methodology for Q-Learning vs Genetic Algorithm"""        def __init__(self, seed=42):        np.random.seed(seed)        self.results = self.generate_mock_results()        def generate_mock_results(self) -> Dict[str, Dict[str, List[float]]]:        """Generate mock experimental results for demonstration"""        # Simulate Q-Learning results        ql_results = {            '5x5': np.random.normal(3.2, 0.15, 30),  # Mean 3.2, std 0.15, 30 runs            '7x7': np.random.normal(3.1, 0.20, 30),  # Mean 3.1, std 0.20            '9x9': np.random.normal(2.9, 0.25, 30),  # Mean 2.9, std 0.25        }                # Simulate Genetic Algorithm results        ga_results = {            '5x5': np.random.normal(3.15, 0.10, 30),  # Mean 3.15, std 0.10            '7x7': np.random.normal(3.05, 0.12, 30),  # Mean 3.05, std 0.12            '9x9': np.random.normal(2.95, 0.15, 30),  # Mean 2.95, std 0.15        }                return {            'q_learning': ql_results,            'genetic_algorithm': ga_results        }        def perform_statistical_analysis(self) -> Dict[str, Dict[str, float]]:        """Perform comprehensive statistical analysis"""        analysis_results = {}                for size in ['5x5', '7x7', '9x9']:            ql_data = self.results['q_learning'][size]            ga_data = self.results['genetic_algorithm'][size]                        # Descriptive statistics            analysis_results[size] = {                'ql_mean': np.mean(ql_data),                'ql_std': np.std(ql_data),                'ql_median': np.median(ql_data),                'ga_mean': np.mean(ga_data),                'ga_std': np.std(ga_data),                'ga_median': np.median(ga_data)            }                        # Normality tests            _, ql_p_normal = stats.shapiro(ql_data)            _, ga_p_normal = stats.shapiro(ga_data)            analysis_results[size]['ql_normal_p'] = ql_p_normal            analysis_results[size]['ga_normal_p'] = ga_p_normal                        # T-test (assuming normality)            t_stat, t_pvalue = stats.ttest_ind(ql_data, ga_data)            analysis_results[size]['t_statistic'] = t_stat            analysis_results[size]['t_pvalue'] = t_pvalue                        # Wilcoxon test (non-parametric)            w_stat, w_pvalue = stats.ranksums(ql_data, ga_data)            analysis_results[size]['wilcoxon_statistic'] = w_stat            analysis_results[size]['wilcoxon_pvalue'] = w_pvalue                        # Effect size (Cohen's d)            pooled_std = np.sqrt(((len(ql_data) - 1) * np.var(ql_data) +                                 (len(ga_data) - 1) * np.var(ga_data)) /                                (len(ql_data) + len(ga_data) - 2))            cohens_d = (np.mean(ql_data) - np.mean(ga_data)) / pooled_std            analysis_results[size]['cohens_d'] = cohens_d                        # Cliff's delta (non-parametric effect size)            cliff_delta = self.cliffs_delta(ql_data, ga_data)            analysis_results[size]['cliffs_delta'] = cliff_delta                return analysis_results        def cliffs_delta(self, x: List[float], y: List[float]) -> float:        """Calculate Cliff's delta effect size"""        nx, ny = len(x), len(y)        greater = 0        equal = 0                for xi in x:            for yi in y:                if xi > yi:                    greater += 1                elif xi == yi:                    equal += 1                return (greater - (nx * ny - greater - equal)) / (nx * ny)        def create_visualizations(self) -> None:        """Create comprehensive visualization of comparison results"""        analysis = self.perform_statistical_analysis()                # Create figure with subplots        fig = plt.figure(figsize=(20, 12))        gs = fig.add_gridspec(3, 4, hspace=0.3, wspace=0.3)                # 1. Box plots for each problem size        for idx, size in enumerate(['5x5', '7x7', '9x5']):            ax = fig.add_subplot(gs[0, idx])            data_to_plot = [                self.results['q_learning'][size],                self.results['genetic_algorithm'][size]            ]                        bp = ax.boxplot(data_to_plot, labels=['Q-Learning', 'GA'], patch_artist=True)            bp['boxes'][0].set_facecolor('lightblue')            bp['boxes'][1].set_facecolor('lightcoral')                        ax.set_title(f'Problem Size: {size}')            ax.set_ylabel('Torque (Nm)')            ax.grid(True, alpha=0.3)                        # Add statistical significance            p_value = analysis[size]['t_pvalue']            significance = '*' if p_value < 0.05 else 'ns'            ax.text(0.5, 0.95, f'p={p_value:.3f} {significance}',                    transform=ax.transAxes, ha='center', va='top')                # 2.
