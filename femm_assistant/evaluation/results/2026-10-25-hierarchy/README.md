Haiku 5.5 and DeepSeek V4 Pro 0813. No live trial reached accepted native
execution. Provider grammar rejection and application handoff errors prevented
scientific assessment; quota, transport and cancellation outcomes are unassessed.

Haiku graph replayed after a general compiler capability fix, using image
`sha256:91708252442140584455886fac463176cf14cfd460a3f4ca2c4c360803d1107b`.
This was not a new model call or a blind-paper pass. It measured
0.00010073645220137112 T against a 0.0001 T analytical field reference
(0.73645% error, frozen 5% tolerance). Native mesh, solver and target checks passed;
mesh/domain convergence for this replay was not established.

evidence. Full decoded trial transcripts and the original replay manifest remain
